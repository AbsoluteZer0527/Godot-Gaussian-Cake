# GCSPLAT v1 and repository boundary

The format is produced by Gaussian Cake's `gc_cli export` and desktop Splats
export. This addon consumes it without linking to the authoring application.
The decoder and Gaussian projection shader originate from that project's
Godot integration example; this repository adds resource import, reusable
players, editor lifecycle handling, independent state, and packaging tests.

The addon version and file-format version are independent. v0.1.0 accepts only
GCSPLAT v1 with flags=1 and stride=56. Unknown versions are rejected rather than
guessed. Topology uses Godot's native glTF/GLB scene importer.

All integers are unsigned 32-bit little-endian. All floats are IEEE-754 float32
little-endian. The header is exactly 64 bytes:

| Offset | Value |
|---:|---|
| 0 | Eight bytes: `GCSPLAT` + zero |
| 8 | u32 version = 1 |
| 12 | u32 header size = 64 |
| 16 | u32 splat count N |
| 20 | u32 frame count F, at least 2 |
| 24 | u32 nominal FPS, 1–120 |
| 28 | u32 flags = 1: linear RGB, view-independent DC color |
| 32 | f32 duration |
| 36 | u32 record stride = 56 |
| 40 | Three f32 AABB minimum coordinates |
| 52 | Three f32 AABB maximum coordinates |
| 64 | F float timestamps, strictly increasing from zero to duration |
| 64 + 4F | F × N records, frame-major; fixed index is splat identity |

Each record stores position XYZ (12 bytes), quaternion **XYZW** (16), natural
logarithm of local-axis standard deviations XYZ (12), linear RGB (12), and
straight opacity (4). File length must equal `64 + 4F + 56NF` exactly.

Between frames the renderer interpolates position, log-scale, linear color, and
opacity linearly; rotation uses shortest-path SLERP. The scale is then
exponentiated. Timestamps are authoritative, including the shortened final
interval of a non-integral-duration clip. Coordinates are right-handed and Y-up.
The exporter already applied normalization and uniform export scale; do not
apply a second axis conversion on import.

The shader projects the rotated 3D covariance into a screen-space ellipse,
adds a 0.3-pixel covariance floor, and evaluates Gaussian alpha. Cache colors
are linear; Compatibility output is converted to sRGB. Colors are prelit, so
the shader is unshaded. IDs are split across two small custom-data values to
avoid Compatibility's half-float precision limit.

The import plugin serializes the validated bytes into a scripted `.res` Resource.
That file lives in `.godot/imported/` and travels through Godot's normal export
dependency system. No runtime `EditorPlugin`, `EditorImportPlugin`, Python,
source PLY, or raw file include filter is needed.

Official references:

- [EditorImportPlugin](https://docs.godotengine.org/en/stable/classes/class_editorimportplugin.html)
- [Making plugins](https://docs.godotengine.org/en/stable/tutorials/plugins/editor/making_plugins.html)
- [3D scene import configuration](https://docs.godotengine.org/en/stable/tutorials/assets_pipeline/importing_3d_scenes/import_configuration.html)
- [MultiMesh](https://docs.godotengine.org/en/stable/classes/class_multimesh.html)

The repository's fixtures are procedural round and tall surfaces generated by
`tools/generate_assets.py`, then exported through Gaussian Cake. They are
independent of the slime playground and complex-transition sample assets.

## GCMAP v1: optional endpoint permutation

GCFORMS endpoint libraries may omit topology and add a `transport_maps` array to
their `library.json`. The `.gcforms` binary and its canonical endpoint IDs remain
unchanged. Each `.gcmap` is little-endian and has exactly `32 + 4N` bytes:

| Offset | Value |
|---:|---|
| 0 | Eight bytes: `GCMAP` followed by three zeros |
| 8 | u32 version = 1 |
| 12 | u32 header size = 32 |
| 16 | u32 identity count N, matching the endpoint library |
| 20 | u32 source form index, matching manifest `names` |
| 24 | u32 destination form index, matching manifest `names` |
| 28 | u32 flags = 1 |
| 32 | N u32 destination canonical IDs, indexed by source canonical ID |

Every ID in `[0,N)` occurs exactly once. Import rejects duplicate, out-of-range,
truncated and trailing entries; unknown versions/flags; identical endpoints; and
counts above the renderer's 50,000 limit. Library loading also validates names,
source/destination indices and counts against the referenced `.gcforms` resource.

```json
{
  "transport_maps": [
    {
      "from": "island",
      "metrics": {
        "after": {
          "objective": 0.11419667848495661,
          "p95_distance": 0.3938125682475011,
          "rms_color": 0.6046899470330906,
          "rms_distance": 0.2634474583960034
        },
        "before": {
          "objective": 0.13540193955405444,
          "p95_distance": 0.49375070440183844,
          "rms_color": 0.6282055639633289,
          "rms_distance": 0.2950563809728673
        },
        "color_weight": 0.3499999940395355,
        "hierarchical_start": true,
        "milliseconds": 2443.0087,
        "neighbors": 24,
        "passes": 8,
        "swaps": 65766
      },
      "path": "transport_1_2_e2fe0349ed1228f7.gcmap",
      "to": "reef"
    }
  ]
}
```

The example is from the included island-to-reef map; use each exported map's actual metrics.
Metrics are informational. They describe the prepared canonical pair, including
average objective and spatial/color errors, not a runtime profiling measurement.

With `transport_mode = "refined"`, display slot `i` reaches canonical destination
`pair_map[current_canonical_ids[i]]`. The permutation is composed through the
current endpoint IDs, so A→B→C→A preserves each endpoint exactly even after a
nonidentity cycle. The destination records are reordered once by a worker when
the transition starts. There is no per-frame endpoint copy or map upload.

Shared-reference playback carries the existing canonical IDs. If an interrupted
pose has no exact source endpoint, refined mode falls back to that stable-ID rule
from a snapshot. `last_transport == "fallback"` makes this explicit. For visual
A/B comparisons, first `snap_to_form(source)` so both runs start with identical
canonical slot order.

The importer packages validated map bytes into a scripted Resource, like the form
library importer. Export the manifest through the JSON include filter; normal
resource export includes the imported maps. Raw `.gcmap` files and editor plugin
code are not needed at runtime. The scene's standalone PCK smoke test checks this.
