# GCSPLAT v1 and repository boundary

The format is produced by Gaussian Cake's `gc_cli export` and desktop Splats
export. This addon consumes it without linking to the authoring application.
The decoder and Gaussian projection shader originate from that project's
Godot integration example; this repository adds resource import, reusable
players, editor lifecycle handling, independent state, and packaging tests.

The addon version and file-format version are independent. v0.1.0 accepts only
GCSPLAT v1 with flags=1 and stride=56. Unknown versions are rejected rather than
guessed. Topology uses Godot's native glTF/GLB scene importer.

All integers are unsigned 32-bit little-endian. All floats are IEEE-754 float32
little-endian. The header is exactly 64 bytes:

| Offset | Value |
|---:|---|
| 0 | Eight bytes: `GCSPLAT` + zero |
| 8 | u32 version = 1 |
| 12 | u32 header size = 64 |
| 16 | u32 splat count N |
| 20 | u32 frame count F, at least 2 |
| 24 | u32 nominal FPS, 1–120 |
| 28 | u32 flags = 1: linear RGB, view-independent DC color |
| 32 | f32 duration |
| 36 | u32 record stride = 56 |
| 40 | Three f32 AABB minimum coordinates |
| 52 | Three f32 AABB maximum coordinates |
| 64 | F float timestamps, strictly increasing from zero to duration |
| 64 + 4F | F × N records, frame-major; fixed index is splat identity |

Each record stores position XYZ (12 bytes), quaternion **XYZW** (16), natural
logarithm of local-axis standard deviations XYZ (12), linear RGB (12), and
straight opacity (4). File length must equal `64 + 4F + 56NF` exactly.

Between frames the renderer interpolates position, log-scale, linear color, and
opacity linearly; rotation uses shortest-path SLERP. The scale is then
exponentiated. Timestamps are authoritative, including the shortened final
interval of a non-integral-duration clip. Coordinates are right-handed and Y-up.
The exporter already applied normalization and uniform export scale; do not
apply a second axis conversion on import.

The shader projects the rotated 3D covariance into a screen-space ellipse,
adds a 0.3-pixel covariance floor, and evaluates Gaussian alpha. Cache colors
are linear; Compatibility output is converted to sRGB. Colors are prelit, so
the shader is unshaded. IDs are split across two small custom-data values to
avoid Compatibility's half-float precision limit.

The import plugin serializes the validated bytes into a scripted `.res` Resource.
That file lives in `.godot/imported/` and travels through Godot's normal export
dependency system. No runtime `EditorPlugin`, `EditorImportPlugin`, Python,
source PLY, or raw file include filter is needed.

The repository's fixtures are procedural round and tall surfaces generated by
`tools/generate_assets.py`, then exported through Gaussian Cake. They are
independent of the future slime game's models and artwork.
